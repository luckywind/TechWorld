# paseo

https://linux.do/t/topic/2401586 Paseo 的核心特点包括：

- 支持多个 Coding Agent 统一管理；
- 支持 Claude Code、Codex、Copilot、OpenCode、Pi 等工具；
- 支持桌面端、移动端、Web 端和 CLI；
- 支持通过二维码连接手机或其他客户端；
- 支持远程连接本机或服务器上的 Paseo daemon；
- 支持通过 relay / WebSocket 实现远程访问能力；
- 适合多模型切换、多 Agent 并行任务、远程查看和移动端掌控。

1. workspace: 

Paseo 的组织结构是围绕工作区展开的，而不是围绕聊天展开的。工作区是执行任务的地方。它包含一个工作目录，并且可以同时运行多个会话。在应用程序中，每个会话都会以标签页的形式打开。

a.项目包含工作区，每个工作区都是一个独立的工作空间

b.工作区包含会话:  会话可以通过tab页切换

c.每个工作区都有一个隔离模式
本地模式：使用现有目录
Worktree: 用于创建或打开一个托管的 Git 工作树。当任务需要自己的目录和分支时，请使用此功能。
